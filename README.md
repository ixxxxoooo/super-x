# Super X - 右侧分栏查看帖子详情 (Chrome 扩展)

在 `https://x.com/home` 等列表页浏览时，**点击左侧时间线上的任意帖子卡片，直接在右侧区域展开该帖子的完整详情与评论列表**，无需离开当前时间线或频繁前进/后退。

## 功能特性

- **左侧点选，右侧即看**：拦截时间线列表卡片点击事件，保持左侧列表滚动位置不变，在右侧区域直接展示原生的帖子详情页（包含完整长文、互动按钮、回复输入框及全部评论）。
- **毫秒级无感切换**：后台预热同源详情容器并接管 X 内部 React Router 路由跳转，切换不同帖子时无需整页刷新，瞬间切换。
- **完整保留原生交互**：
  - 点击卡片上的 **点赞、转帖、回复、书签、分享、更多(`...`)、头像/个人主页链接、话题标签、图片预览、视频播放** 等元素时，保持 X 原生行为。
  - 支持点击 **引用推文 (Quoted Tweet)** 及 **「显示更多」** 直接在右侧展开对应帖子详情。
- **选中高亮与宽度调节**：
  - 左侧列表自动高亮当前正在右侧查看的帖子卡片。
  - 支持拖动右侧详情栏左边缘自由调节分栏宽度（双击分割线可恢复自适应宽度）。
  - 自动适配 X 的 **浅色 / 黯淡 / 纯黑** 三种主题模式。
  - 按 `Esc` 键、点击详情左上角 `←` 返回键或右上角 `✕` 按钮即可关闭右侧详情栏，恢复原右侧搜索栏。

## 安装方式

1. 打开 Chrome / Edge / Brave / Arc 浏览器，访问扩展管理页：`chrome://extensions/`
2. 打开右上角的 **「开发者模式」(Developer mode)** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」(Load unpacked)**。
4. 选择本项目所在目录：`/Users/liwenjiao/super-x`。
5. 打开或刷新 [`https://x.com/home`](https://x.com/home)，点击左侧任意帖子卡片即可在右侧查看详情！
